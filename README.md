# CORSO I.A.

Piattaforma didattica in italiano dedicata all'intelligenza artificiale, ChatGPT, Work, Codex, automazioni e agenti AI.

## Piano approvato

- 8 moduli, 32 lezioni.
- Interfaccia mobile-first per iPhone, compatibile con Windows.
- Pubblicazione prevista mediante GitHub Pages.
- Download dei moduli e consultazione offline da progettare e collaudare su iPhone.
- La precedente V0.1 rimane una demo separata.

## Stato

Repository inizializzato. Il codice della piattaforma e i materiali didattici non sono ancora stati caricati o pubblicati. I video del prototipo sono bozze, non lezioni definitive.

Non inserire password, token o sorgenti di altri progetti in questo repository.
